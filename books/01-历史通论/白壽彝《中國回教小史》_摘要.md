# 白壽彝《中國回教小史》

**類型**：書目摘要
**作者**：白壽彝（1909-2000）
**出版**：1943年發表於《邊政公論》，1944年商務印書館出版，1982年收入《中國伊斯蘭史存稿》
**全書結構**：9章，從唐至20世紀上半葉

| 章 | 內容 | 對應時代/主題 |
|----|------|-------------|
| 第一章 | 中國大食的交通 | 唐以前及唐：海陸路線（賈耽四夷路程） |
| 第二章 | 大食商人的東來 | 唐：朝貢使性質、蕃坊制度 |
| 第三章 | 大食法之記載 | 唐：杜環《經行記》等最早記錄 |
| 第四章 | 禮堂和公共墓地的創建 | 唐宋：清真寺與墓碑考古 |
| 第五章 | 回回之始盛 | 元：色目人政治地位 |
| 第六章 | 歧視與厄害之發生 | 明清：壓迫與回民起義 |
| 第七章 | 寺院教育的提倡 | 明清：經堂教育（胡登洲） |

## 核心分期框架
白壽彝將中國伊斯蘭史分為兩個時期：
1. **移植時期（唐宋元）**——以外籍穆斯林為主，伊斯蘭在中國「移植」
2. **厄難時期（明清）**——各族穆斯林已是中華民族組成部分，但受歧視與迫害
