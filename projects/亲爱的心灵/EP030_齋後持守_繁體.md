# EP030 齋後持守

使者ﷺ說：「吉卜利勒（願他平安）來到我面前說：任你愛你所愛之人，終將與之分離；任你活多久，終將一死；任你為所欲為，終將為此受到回報或清算。」

齋戒月即將結束，最重要的問題依然存在：我的心靈狀態如何？

在這最後一集中，我們將回顧心靈的完整旅程——從使其暗淡的病症，到打磨它的良方；從傲慢、憤怒與嫉妒，到記主ﷻ、誦讀與真誠懺悔。並探討：齋戒月後的規劃為何至關重要，以及如何讓靈性的轉變持續下去。

當我們出生時，真主ﷻ賜予我們一顆純潔如水晶般清澈的心。隨著人生經歷，這顆水晶會因我們的環境、所見所聞、所交往的人而一點一點變髒。但真主ﷻ也賜予了清潔劑，讓我們能隨時恢復和清潔它。

你準備好帶著一顆清潔的心去面見真主ﷻ了嗎？

什麼使心靈變髒？

第一，言語。我們所說的話，必須經過舌頭過濾。確保所言幾乎總是取悅真主ﷻ的。

第二，視聽。遠離非法之物。祈求真主ﷻ幫助你安排時間——時間與舌頭一樣，若不用在取悅真主ﷻ上，便會用在相反的方向。

第三，內心的情感。是否自視高人一等？是否看不起人？是否心懷憤怒？是否說謊？審視它們，逐一認識它們。

第四，過度。過多的食物、過多的言談、過多的人際交往、過多地觀看非法甚至合法的事物——全都會腐蝕心靈。

根本的療法。

真主ﷻ的慈憫在於：心雖然極易變髒，也同樣極易被清潔。

每做一件善行，就能消除一件惡行。使者ﷺ說：「你當用一件善行緊隨一件惡行，它會將它徹底抹除。」

每日心靈自省。

給自己心靈拍一張「自拍」：今天我留下了什麼黑點？我使用了什麼療法來清潔它？

- 我記念真主ﷻ了嗎？
- 我誦讀古蘭經了嗎？
- 我向真主ﷻ求饒恕了嗎？
- 我向先知ﷺ祝福了嗎？
- 我的主命拜與齋戒月時一樣嗎？
- 我禮夜間拜了嗎？
- 我與聖行和真主ﷻ經典的關係如何？

齋戒月是訓練營。

真主ﷻ在一年中設置了多個訓練營，齋戒月是最大的一個——為期三十天。既然能在齋戒月做到，之後也能做到。

齋戒不要止步於齋戒月。每週封一天齋，或每月三天，讓它成為習慣。

古蘭經是最好的清潔劑。不要在齋戒月後遠離它。誦讀、學習、理解、背誦——哪怕只保持齋戒月時的一半。

不要讓清真寺恢復空蕩。走向清真寺的每一步，一步消除罪過，一步記錄善行。

你潔淨了嗎？

主啊，求祢把敬畏賜予我們，並淨化我們的心靈，祢是最善於淨化我們的主。主啊，求祢接受我們的善功，饒恕我們的過錯。主啊，求祢不要讓這個齋戒月成為最後一個。求祢賜予我們更多歲月，並賜我們能幹善功的能力。阿敏。
